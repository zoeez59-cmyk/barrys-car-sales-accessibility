Suggested student task:
1. Evaluate the supplied site for accessibility and usability problems.
2. Use WAVE as part of the accessibility evaluation.
3. Carry out appropriate manual checks as well.
4. Modify the supplied files to address the issues you identify.
5. Re-test the revised site and explain and justify your changes.

Important:
Automated tools do not establish complete conformance. Students should interpret tool findings and apply manual judgement.
